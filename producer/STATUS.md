# Status

**Phase:** 1 done (visual proof) → moving into Phase 2 wrap-up
**Last updated:** Nov 1, 2026

## What works right now
- The game runs in the browser: title screen, a 16×12 garden with a hedge border, top bar (coins, orders, pause/speed, undo, zoom, help, settings), order panel, build palette, inspector, tutorial card, notifications, settings and completion screens.
- You can place Daisy Beds, drag belts, place a Packing Station, rotate, remove (full refund), undo, and watch daisies grow and travel along belts into the station. Orders complete and pay coins, and the next tool unlocks.
- All later machines (Lavender Bed, Bundling Table, Drying Bench, Arrangement Table) are implemented and unlock as orders progress; the full six-order run passes in automated tests.
- Saving is automatic (local browser storage). Continue / New game on the title screen.
- Screenshots of the current look are in `producer/shots/` (00 title, 01 fresh garden, 02 first chain, 03 inspector, 04 all machines, 05 build ghost, 06 settings).

## Art
- All art on screen is **interim**, generated by `tools/make_interim_art.py` into `assets/interim/`. It follows the palette and reads clearly, but it is not the final gouache look.
- The art team drops final files into `assets/art/` using the names in `docs/ASSET_SPECS.md`; each file replaces its stand-in automatically, no code changes.
